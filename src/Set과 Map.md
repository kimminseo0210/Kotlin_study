🚀 핵심 자료구조 요약 : Set과 Map
==
대용량으로 트래픽을 처리하는 서버 환경에서 데이터 탐색 속도를 `O(1)`(상수시간)로 끌어올리기 위해 필수적으로 사용하는 해시(Hash) 기반의 자료구조

## 1. Set(집합)
"오직 '존재 유무'와 '중복 제거'에만 집중하는 주머니"
`Set`은 <b>데이터의 순서를 보장하지 않으며</b>, 동일한 데이터가 <b>두 번이나 들어가는 것을 절대 허락하지 않음</b>
- 핵심 동작 원리 : 데이터를 넣으면 해시 함수를 통해 즉시 고유한 주소값을 계산하여 저장, 따라서 데이터를 찾을 때도 처음부터 뒤지지 않고, 단번에 해당 주소를 찾음
- 시간 복잡도 : `O(1)`(탐색, 삽입, 삭제 모두 빛의 속도)
- 실무 예시 : 
  - 중복 방지 : 이미 가입된 이메일이나 휴대전화 번호인지 확인할 때
  - 방문 기록 : 특정 유저가 오늘 출석체크 이벤트를 이미 참여했는지 여부 (`contains`)
  - 블랙리스트 : 악성 유저의 IP가 차단 목록에 포함되어 있는지 검사 할 때  
- 💻 Kotlin 코드 스니펫
```kotlin
val blockedIps = HashSet<String>()
blockedIps.add("192.168.0.1")
blockedIps.add("192.168.0.1") // 중복된 값은 무시됨 (크기는 여전히 1)

// 리스트의 for문 대신 단 한 줄로 존재 여부 확인 (O(1))
if (blockedIps.contains("192.168.0.1")) {
    println("차단된 IP입니다.")
}
```

## 2. Map (맵/사전) 
"열쇠(key)를 주면, 짝꿍 데이터(Value)를 내어주는 보관함"  
`Map`은 항상 `key`와 `Value`가 한 쌍으로 움직임. `key`는 `Set`처럼 중복될 수 없는 고유한 값이어야 하지만, `value`는 중복되어도 상관 없음

- 핵심 동작 원리 : `key`를 해시 함수에 넣어 주소값을 계산한 뒤, 그 위치에 `value`를 보관. 원하는 `value`를 찾으려면 반드시 그에 맞는 `key`를 제시해야 함
- 시간 복잡도 : `O(1)`(`key`를 이용한 탐색 기준)
- 실무 예시 :
  - 연관 데이터 조회 : 회원ID(`key`)로 유저의 상태 정보(`value`)를 빠르게 블러올 때
  - 빈도수 카운팅 : 특정상품(`key`)이 오늘 몇 개(`value`) 팔렸는지 집계할 때
  - 캐싱(Caching) : 복잡하고 오래 걸리는 계산 결과를 `Map`에 임시 저장해 두고, 똑같은 요청이 오면 재계산 없이 바로 꺼내올 때
- 💻 Kotlin 코드 스니펫
```kotlin
// <Key 타입, Value 타입>
val userPoints = HashMap<String, Int>()

// 데이터 삽입 및 갱신
userPoints["Minseo"] = 1500  // 회원가입 축하금 지급
userPoints["Minseo"] = userPoints.getOrDefault("Minseo", 0) + 500 // 포인트 500점 추가

// Key를 통한 초고속 데이터 조회
println("현재 포인트: ${userPoints["Minseo"]}")
```

### 📊 한눈에 보는 비교 총정리
| 구분       | List(리스트)            | Set(집합)              | Map(맵)                             |
|----------|----------------------|----------------------|------------------------------------|
| 특징       | 순서가 있는 번호표 줄서기       | 순서 없는 마법 주머니         | key-value 짝 보관함                    |
| 중복 허용    | O                    | X                    | key : X / value : O                |
| 탐색 속도    | O(N) (처음부터 다)        | O(1) (단번에 찾음)        | O(1) (key로 단번에)                    |
| 주요목적     | 순서대로 데이터를 나열할 때      | 포함 여부(`contains) 확인  | 특정 key의 데이터(`value`)를 찾을 때         |
| 자주 쓰는 함수 | `add()`, `get(index)` | `add()`, `contains()` | `put()`,`get(key)`, `containsKey()` |
