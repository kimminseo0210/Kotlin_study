Kotlin 배열
==

## 배열선언 방식 
1. `int`배열
   - 값을 알고 있을 때
     ```kotlin
     fun main() {
        val numbers = intArrayOf(10,20,30,40,50)
     }
     ```
   - 크기만 정할 때
     ```kotlin
     fun main() {
        val n = readln().toInt()
        val number = IntArray(n) // 크기가 n이고 0으로 가득찬 배열
     }
     ```
     
2. 문자 배열
    - 문자열 등 객체를 담는 배열
      ```kotlin
      fun main() {
          val strings = arrayOf("kim", "min", "seo")
      }
      ```
    - `String`배열 선언 독특함
      ```kotlin
      fun main() {
          val n = readln().toInt()
          val arr = Array(n) {""}       // 빈문자열("")로 채워진 배열
          val arr2 = Array(n) {"min"}   // "min"으로 꽉 채워진 배열
          val names = arrayOf("min","reo")
      }
      ```
      
3. 내부 값 확인
    - 배열 크기 확인`.size`사용
    - 배열의 내부 값을 한 눈에 보고싶을땐
      `println(arr.contentToString())` -> `[1,2,3]`
        처럼 예쁘게 출력됨
    - `joinToString()` 내가 원하는대로 출력 (구분자를 기준으로)
      - `joinToString(" ")`공백으로 합치기 -> 1 2 3
      - `joinToString(", ")`공백+쉼표 -> 1, 2, 3
      - 괄호도 붙이고 싶다면 `joinToString(separator = ", ", prefix="[", postfix="]")` -> [1, 2, 3]
