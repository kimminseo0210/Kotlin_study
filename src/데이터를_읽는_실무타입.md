Data를 읽는 방법
==
실무에서는 데이터 원본을 바꾸는 것이 아닌 읽는 방식을 수정하는 것을 원한다

## `downTo` vs `reversed()`
1. `downTo`방식 (인덱스 직접 제어)
문자열을 뒤집지 않고, 읽는 순서만 뒤에서부터 시작하는 방식
- 코드 : `for (i in N.lenght - 1 downTo 0)`
- 순서 : 4(index) 3 2 1 0
- 장점 : 문자열을 새로 만드는 과정이 없어 <b>메모리 절약 가능, 속도 빠름</b>

2. `reversed()` 방식 (데이터 뒤집기)
문자열 자체를 거꾸로 뒤집은 새 문자열을 만들고, 앞에서부터 읽는 방식
- 코드 : `for (char in N.reversed())`
- 순서 : 뒤집힌 문자열의 0->1->2...
- 단점 : 문자열이 아주 길면 뒤집는 데 메모리와 시간이 추가됨

3. `step`
기존의 한 칸씩이 아닌 몇 칸씩 뛰어넘고 싶을 때
`for (i in 10 downTo 0 step 2)`
-> 10,8,6,4,2
