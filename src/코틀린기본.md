Kotlin의 기본
==

## 변수 선언
1. val(Value) : 변하지 않는 값을 넣을 때 사용
2. var(Variable) : 변하는 값, 자바의 일반적인 변수처럼 사용 -> 언제든지 값을 변경할 수 있음  
3. 간단 예시  
    ```kotlin
    fun main() {
    val a = 10
    // a =20 <-- 오류 발생 val은 한번 정하면 끝
    
    var b =10
    v = 20  // 정상 작동 var은 언제든지 바꿀 수 있음
    }
    ```
4. 실무 권장 스타일
    - 의도치 않게 값이 변경되어 오류가 나지 않도록 <b>기본적으로 무조건 `val`을 먼저 사용</b>
    - 반복문의 카운트처럼 꼭 변하는 값이라면 `var`사용

5. 변수 타입 선언 가능
   - 코틀린의 컴파일러는 타입 추론 능력이 뛰어나서 따로 저정을 해줄 필요없음
      ```kotlin
     fun main() {
        val a = 10          // 변수에 숫자가 있네 -> int 타입
        val name = "min"    // 변수에 문자가 있네 -> String 타입
     }
      ```
   - 변수 상자를 먼저 만들어 놓고 사용할 때
      ```kotlin
     fun main() {
        val result : String
        if (조건) {
            result = "합격"
        } else {
            result = "불합격"
        }
     }
      ```
     이렇게 해당 변수의 목적을 먼저 만들어 놓고 사용

## 반복문
1. `if`문
   - 코틀린에서는 가장 기본적인 `if-else`문의 형태를 편하게 만들 수 있는 기능이 있음
   ```kotlin
    fun main() {
        val result = if (a>b) ">" else if (a<b) "<" else "=="
        println(result)
    }
    ```
   이런식으로 변수에 직접적인 `if-else`문을 넣을 수 있음  


2. `while`문
   - 자바의 `switch-case`문을 완벽하게 대체하는 코틀린의 꽃,  
    지루한 `case`나 `break` 키워드 없이 화살표로 직관적 조건을 할 수 있음
   ```kotlin
    fun main() {
        when {
            a>b -> println(">")
            a<b -> println("<")
            else -> println("==")
        }    
    }
    ```
   이렇게 조건과 화살표로 직관적이게 나타낼 수 있음
3. `for`문
   - 자바에서 쓰던 `for(int i=0; i<n; i++)`형태는 코틀린에서는 완전 사라진 문법으로, 대신 `in`과 `..(범위연산자)`를 사용하여 영어 문장처럼 깔끔 직관적이게 작성
   ```kotlin
   fun main() {
      for (i in 1..n) {
          // 반복할 내용
      }
   ```
   - 별 찍기와 같이 문장 반복이 필요할 때는 자바의 2중 `for`문이 아닌 `repeat()`를 사용한다
   ```kotlin
   fun main() {
       var stars = "*".repeat(3)
       println(stars)
   }
   ```
