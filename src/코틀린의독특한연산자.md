Kotlin의 독특한 연산자
==

### 1. 엘비스 연산자`?:`
'엘비스의 풍성하게 빗어 넘긴 앞머리'같다고 하여 붙여진 이름

    - 작동 원리 : 왼쪽 값이 `null`이면, 오른쪽 값을 대신 써라
      - 기본 형태 : `A ?: B`
      - Java와 비교
        ```kotlin
        fun main() {
           val name: String? = null
           val result : String
           if (name != null) {
               result = name
           } else {
               result = "*"
           }
        }
        ```
      - 엘비스 연산자 활용
        ```kotlin
        fun main() {
            val name : String? = null
            val result = name ?: "*"
        }
        ```

### 2. 배열 관련 팁
1. 반복 및 순회 (데이터를 훑을 떄)
   - `indices` : 방 번호(인덱스)만 필요해
     - 사용 : `for (i in array.indices)`
     - 결과 : `0, 1, 2, ...` 인덱스 범위
   - `withIndex()` : 방 번호, 알맹이 둘 다 필요
     - 사용 : `for ((index, value) in array.withIndex())`
     - 결과 : `(0, A), (1,B), ...` 쌍으로 나옴
   - `forEach` : 그냥 하나씩 꺼내서 뭔가 실행만 할래
     - 사용 : `array.forEach { println(it) }`

2. 필터링 및 추출 
    - `filter` : 조건에 맞는 알맹이만 뽑아줘
      - ex: `num.filter { it > 0 }` 0보다 큰 값을 모은 새 리스트
    - `filterIndexed` : 방 번호도 보고 조건도 따져서 뽑아줘
      - ex: `num.filterIdexed { index, value -> index % 2 == 0 }` 짝수 번째 방만 추출
    - `distinct()` : 중복된 알맹이는 하나씩 남겨줘
      - ex: `listOf(1, 1, 2).distinct()` -> `[1,2]`

3. 데이터 변환 (모양을 바꿀 때)
   - `map` : 모든 알맹이를 내가 시키는 대로 변환 ㄱ
     - ex: `word.map { it.uppercase() }` 전부 대문자로 변환
   - `mapIndexed` : 방 번호 참고해서 변신 ㄱ
     - ex: `num.mapIndexed { i,v -> i + v }` 인덱스와 값을 더함

4. 수치 계산 (합계나 최댓값)
   - `sum()` / `sumOf` : 다 더해줘
     - ex: `num.sum()`, `items.sumOf { it.price }`
   - `maxOrNull()`, `minOrNull` : 가장 큰 거(작언 거) 하나만 가져와
     - 주의 : 값이 없을 수도 있어서 결과가 `Null`일 수 있음
   - `count { ... }` : 조건에 맞는 게 몇개인지 세어줘
     - ex: `num.count { it > 10 }` 10보다 큰 숫자의 개수

```kotlin
// 1. 방 번호 순회
for (i in arr.indices) { ... }

// 2. 번호 + 값 동시 순회 (강력 추천)
for ((idx, value) in arr.withIndex()) { ... }

// 3. 조건 필터링
val positive = arr.filter { it > 0 }

// 4. 전체 변환
val upper = words.map { it.uppercase() }

// 5. 조건에 맞는 개수 세기
val count = arr.count { it == maxVal }
```
