Kotlin의 독특한 연산자
==

 1. 엘비스 연산자`?:`
'엘비스의 풍성하게 빗어 넘긴 앞머리'같다고 하여 붙여진 이름

    - 작동 원리 : 왼쪽 값이 `null`이면, 오른쪽 값을 대신 써라
      - 기본 형태 : `A ?: B`
      - Java와 비교
        ```kotlin
        fun main() {
           val name: String? = null
           val result : String
           if (name != null) {
               result = name
           } else {
               result = "*"
           }
        }
        ```
      - 엘비스 연산자 활용
        ```kotlin
        fun main() {
            val name : String? = null
            val result = name ?: "*"
        }
        ```
